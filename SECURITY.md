# Security policy

## Sensitive information

Do not commit credentials, tokens, private email addresses, visitor submissions, generated vCards, or Google Apps Script secrets. Store the notification address in Apps Script Properties as `NOTIFICATION_EMAIL`.

If sensitive information is committed accidentally, remove it from the repository and rotate or replace the exposed value immediately.

## Reporting an issue

Until a dedicated security contact is configured, report security concerns to the repository owner privately rather than opening a public issue containing personal information.
