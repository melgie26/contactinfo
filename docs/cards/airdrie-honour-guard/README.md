# AFDCS Honour Guard Digital Contact Card

Static, mobile-first contact page for the Airdrie Fire Department Ceremonial Society Honour Guard Executive Board.

The page provides a shared board email, an organization vCard, and direct call, email, text, and vCard actions for each executive member. It has no database, credentials, analytics, or visitor-data collection.

## Public location

When deployed with the existing `contactinfo` GitHub Pages site, the expected address is:

`https://melgie26.github.io/contactinfo/cards/airdrie-honour-guard/`

Use that exact HTTPS address for both NFC programming and QR-code generation after confirming the published page.
